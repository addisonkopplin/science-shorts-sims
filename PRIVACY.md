# Privacy Policy: Shorts Poster

_Last updated: October 19, 2026_

Shorts Poster is a personal tool used only by the owner of the YouTube channel @addisonkopplin to upload videos, update video details, and read and reply to comments on that channel, using the YouTube Data API.

**What it accesses.** With the channel owner's permission, it accesses that owner's own YouTube channel data (videos, playlists, comments, and basic analytics) through Google's OAuth.

**How data is used.** Data is used only to manage the owner's own channel. It is not sold, shared with third parties, used for advertising, or used to train AI models.

**Storage.** Access tokens are stored privately on the owner's own machine and are never published. No data from other users is collected.

**Revoking access.** Access can be revoked at any time at https://myaccount.google.com/permissions.

Shorts Poster's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Contact.** Open an issue at https://github.com/addisonkopplin/science-shorts-sims/issues.
